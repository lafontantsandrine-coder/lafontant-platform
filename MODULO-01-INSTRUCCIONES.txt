MÓDULO 01 — AUTENTICACIÓN

1. Abre este ZIP.
2. Copia TODO su contenido.
3. Pégalo dentro de:
   C:\Lafontant\lafontant-platform
4. Cuando Windows pregunte, elige:
   Reemplazar los archivos en el destino.
5. Abre GitHub Desktop.
6. Summary:
   v1.1.0 - Authentication module
7. Commit to main.
8. Push origin.
9. En Hostinger, haz Redeploy usando el ZIP actual o conecta el nuevo código cuando esté disponible.

IMPORTANTE:
El build ejecutará "prisma db push" para crear las tablas en Supabase.
La recuperación de contraseña muestra el flujo, pero el envío real de correos
se conectará después con un proveedor de email.
