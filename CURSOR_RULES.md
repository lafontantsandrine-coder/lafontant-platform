# Lafontant Learning Platform - Cursor Rules

## General Rules

Never change business logic unless explicitly requested.

Always preserve TypeScript types.

Never create duplicate components.

Never modify files outside the requested scope.

Keep the project with zero TypeScript errors.

Never use CSS Modules.

Use only the Lafontant Design System.

---

## UI Rules

Always use:

Button

Input

Card

Badge

Checkbox

Loader

Never recreate HTML already available as reusable components.

---

## Styling Rules

Never hardcode colors.

Never hardcode spacing.

Never hardcode border radius.

Always use:

theme.colors

theme.spacing

theme.radius

theme.typography

theme.shadows

---

## Accessibility

Always include:

aria-label

aria-invalid

aria-describedby

forwardRef when appropriate

useId when necessary

Keyboard accessibility.

---

## Text

Never hardcode interface text.

Use props whenever possible.

Never leave English placeholder text.

---

## Icons

Never use emojis.

Use SVG icons.

Do not use external icon libraries unless requested.

---

## Architecture

Follow the existing folder structure.

Keep components reusable.

Keep functions small.

Avoid duplicated code.

Always prefer composition over repetition.

---

## Quality

Project must always compile.

Problems panel must stay at zero.

Code must be production-ready.
