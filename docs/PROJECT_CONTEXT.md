Simple

Interactive

Beautiful

Motivating

Professional

---

## Audio

Every vocabulary item and every example sentence will use professional human audio.

Audio is generated outside the platform using SuitBlaster.

The platform must allow replacing every audio easily.

Never use browser speech synthesis in production.

---
