# Cursor Rules

## General

- Modify only the requested files.
- Never change business logic unless requested.
- Keep Problems = 0.
- Never duplicate components.
- Reuse existing components.
- Stop when the task is finished.

---

## Design System

Always use existing UI components.

Never create new Button, Input, Card or Badge if one already exists.

Do not hardcode:

- Colors
- Radius
- Shadows
- Typography
- Spacing

Use the Design System.

---

## Architecture

Respect the folder structure.

Do not move files unless explicitly requested.

Do not create new folders unless requested.

Keep components reusable.

---

## Code

Prefer composition.

Keep functions small.

Use TypeScript.

Keep production-ready code.

---

## Accessibility

Use:

- forwardRef
- useId
- aria-label
- aria-invalid
- aria-describedby

when appropriate.

---

## Workflow

Modify only the requested files.

Finish one task before starting another.

Do not continue after completing the requested task.
